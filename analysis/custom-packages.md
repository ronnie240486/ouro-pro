# Pacotes auxiliares recuperados

Além de `com.ouropro.player`, a saída do JADX continha pacotes auxiliares aparentemente empacotados no APK. Foram copiados para o projeto reconstruído os namespaces `com.rtx`, `iptv.m3u`, `com.diegodev`, `com.evgenii` e `at.huber`. Bibliotecas públicas AndroidX, Retrofit, OkHttp, ExoPlayer, Glide, Realm e Volley serão declaradas como dependências, não duplicadas no código-fonte.
